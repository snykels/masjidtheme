## v6
هذه النسخة أعيدت معايرتها بعد إصلاح محرك Absolute Layout نفسه.

التغييرات:
- الإحداثيات أصبحت مطلقة ولا تنعكس مع RTL.
- صفوف الصلاة تتمدد لتملأ كامل مساحة prayerTable.
- إزالة padding الافتراضي للثيمات المطلقة.
- إظهار اسم الصلاة بالعربية والإنجليزية أسفلها.
- خلفية خفيفة لكل صف مع تظليل أوضح للصلاة النشطة.
- فاصل رأسي اختياري في Landscape.
- إظهار اسم المسجد أعلى الساعة كعنصر ديناميكي.
- تكبير الساعة وأوقات الصلاة والتواريخ مقارنة بـ v5.
- لا يوجد اسم الشركة أو النص التجاري الظاهر أسفل صور المرجع.
