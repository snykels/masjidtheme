# القوس التراثي

## النسخة الحالية
- Theme version: 8

## v8
أعيد بناء الثيم للاستفادة من محرك الأشكال والتحكم المفتوح بالأحجام.

### التطابق مع المرجع
- التاريخ الميلادي والهجري مفصولان إلى: يوم / شهر / سنة.
- أرقام الأيام داخل دوائر زخرفية مستقلة.
- الساعة كبيرة في موضعها المرجعي.
- شعار المسجد عنصر مستقل أعلى الساعة.
- اسم اليوم في المنتصف.
- جدول الصلاة مضبوط بحجم مستقل لكل: الوقت / الاسم العربي / الاسم الإنجليزي / AM-PM.
- صفوف رمادية شفافة، والصلاة النشطة بتظليل بيج.
- Landscape يحتوي فاصل رأسي دقيق.
- العد التنازلي كسطر واحد: prayer remaining {prayerEn} for {minutes} minutes.
- لا يوجد اسم الشركة أو ALRBEA TIMES داخل الثيم.
