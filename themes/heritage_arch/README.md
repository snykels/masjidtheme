# القوس التراثي

ثيم مستوحى من واجهة تراثية مزخرفة بألوان فحمية وعاجية ولمسات ذهبية.

## الحالة
- layout/layout.json: جاهز
- manifest.json: جاهز
- assets/portrait.webp: بانتظار الخلفية النظيفة
- assets/landscape.webp: بانتظار الخلفية النظيفة
- dist/heritage_arch.masjidtheme: يُنشأ بعد إضافة الخلفيتين

## ملاحظات التصميم
- لا توجد كروت أو ظلال برمجية؛ تفاصيل الصفوف والزخارف تكون ضمن الخلفية.
- الساعة والتواريخ وأوقات الصلاة والعد التنازلي ديناميكية.
- اسم المسجد والحرارة والإقامة والأذكار وQR مخفية لتطابق المرجع.
- لا يتطلب layout.json الحالي خطًا خارجيًا لأنه لا يحتوي مفتاح fontFamily.

## التسمية
لا يعتمد الثيم على رقم تسلسلي داخل الاسم أو المسار. الترتيب والعرض في التطبيق يجب أن يُدارا من فهرس الثيمات/واجهة التطبيق، وليس من اسم ملف الحزمة.
