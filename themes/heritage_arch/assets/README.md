# Assets — القوس التراثي

ضع الخلفيتين النظيفتين هنا بالأسماء التالية حرفيًا:

- `portrait.webp`
- `landscape.webp`

يجب أن تحتوي الخلفيات على العناصر الثابتة فقط: الإطار، الزخارف، الأقواس، الشرائط والخطوط/الشعارات الثابتة.
لا تضع الساعة أو التواريخ أو أوقات الصلاة أو العد التنازلي داخل الصور لأنها تُعرض ديناميكيًا من التطبيق.
